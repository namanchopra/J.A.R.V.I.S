## Manual checks

### 1. Push-to-talk flow
- [ ] Open Jarvis (full HUD visible).
- [ ] Press and hold the default hotkey (`⌥ + Space`).
- [ ] The Wails window resizes to a small 180×180 box pinned to the configured corner (default: top-right). Overlay orb visible.
- [ ] Orb transitions from `idle` → `listening` while the hotkey is held.
- [ ] Speak the word "test".
- [ ] Release the hotkey.
- [ ] Daemon transcribes "test" (visible in log: `STT final: test`).
- [ ] LLM responds via TTS, orb transitions to `speaking` during playback.

### 2. Manual close
- [ ] After the bot finishes speaking, click the close button (× in the top-right corner of the overlay).
- [ ] Window restores to its prior size and position exactly.
- [ ] Always-on-top flag is cleared (other apps can cover the window again).

### 3. Hotkey rebind
- [ ] Open Settings → Overlay tab.
- [ ] Current hotkey shows as `⌥ + Space`.
- [ ] Click the hotkey field to enter capture mode.
- [ ] Press `⌃ + ⇧ + J` (Ctrl+Shift+J).
- [ ] Field updates to show `⌃ ⇧ J`.
- [ ] `~/.jarvis/config.json` now contains `"overlayHotkey": "ctrl+shift+j"` (verify with `grep -i overlayHotkey ~/.jarvis/config.json`).
- [ ] `⌥ + Space` no longer triggers the overlay (try it).
- [ ] `⌃ + ⇧ + J` triggers the overlay (try it).

### 4. Reserved-shortcut blocklist
- [ ] In Settings → Overlay, click the hotkey field again.
- [ ] Press `⌘ + Q` (Cmd+Q).
- [ ] Field does NOT update; an inline warning appears: "this shortcut is reserved" (or equivalent).
- [ ] Warning dismisses automatically after ~3 seconds.
- [ ] Press `Escape` to cancel capture mode.

### 5. Accessibility-denied graceful failure
- [ ] System Settings → Privacy & Security → Accessibility → toggle Jarvis OFF.
- [ ] Restart Jarvis.
- [ ] App still launches (does NOT crash on startup).
- [ ] Settings → Overlay tab shows a warning row: "Couldn't register the global hotkey. Grant Jarvis Accessibility access in System Settings."
- [ ] Click the warning's "Open System Settings" button → System Settings opens to the Accessibility pane.
- [ ] Re-grant Accessibility, restart Jarvis, confirm warning row disappears.

### 6. Position config
- [ ] Settings → Overlay → change Position to `Bottom right`. Save.
- [ ] Trigger the hotkey. Overlay appears in the bottom-right corner.
- [ ] Repeat for `Top left` and `Bottom left`. Each corner places the window correctly with a ~20 px gutter.

### 7. Show transcript chip (optional polish)
- [ ] Settings → Overlay → toggle "Show transcript chip" ON. Save.
- [ ] Trigger the hotkey. Overlay shows a small chip below the orb.
  (Chip content is a stub `"..."` per the v0.3.0 implementation note — content wiring is a follow-up.)
